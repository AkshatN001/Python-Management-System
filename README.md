# Python Management System

A menu-driven Python application designed to manage different operations through a modular programming approach.

## Features

- **Attendance Management** – Manage student attendance.
- **Billing Management** – Handle billing operations.
- **Expense Management** – Add, view and summarize expenses.
- **Grading System** – Manage student grades.
- **Reports** – Generate and display reports.
- **Input Validation** – Validate user inputs to prevent invalid entries.

## Technologies Used

- Python 3
- Python Modules
- Functions
- Conditional Statements
- Loops
- Input Validation

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/AkshatN001/Python-Management-System.git
```

2. Open the project folder.

3. Run the main Python file:

```bash
python main.py
```
